# Mapaverse corrections

[Mapaverse](https://mapaverse.com) is an unofficial fan map of the worlds of the Marvel universe across the films, the comics and the Fox X-Men films. Every fact on it comes from a public source, and every page links to the source it used. When something is wrong, this is where to say so.

## How to file a correction

1. Open the page on mapaverse.com where the mistake appears and use its **Suggest a correction** link. That opens a form here with the page address already filled in. You can also start one from [New issue](../../issues/new/choose).
2. Pick the form that fits:
   - **Wrong date**: an event, a film or a period sits in the wrong year or era.
   - **Wrong location**: a character's home, a trip, or where something happened is on the wrong world.
   - **Missing character**: someone who belongs on the map is not there.
   - **Other**: anything else, including wrong relationships, statuses or summaries.
3. Say three things:
   - **Which page**: the mapaverse.com address.
   - **What is wrong**: quote or describe what the page says now.
   - **The source**: where the right answer comes from. A fan-wiki page, a comic issue (title, volume and number), or a film or episode with a rough timestamp. Corrections without a source cannot be checked, so they wait until one is added.

## What happens next

Each correction is checked against its source. Accepted fixes go into the next data update with the reasoning kept alongside the data, and the issue is closed with a note saying what changed. If two sources disagree, the map shows both readings rather than picking one.

## What this repository is not

It holds no code and no data, only correction requests. Please do not post copyrighted images, scans or long passages from the wikis or comics; a link and a short description are enough.
